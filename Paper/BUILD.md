## Building

From this directory:

```
pdflatex main
bibtex   main
pdflatex main
pdflatex main
```

`elsarticle.cls` ships with TeX Live and MiKTeX. If it is missing:
`tlmgr install elsarticle` (TeX Live) or let MiKTeX install it on demand.

The easiest route is Overleaf — upload `main.tex` and `refs.bib`, set the
compiler to pdfLaTeX. Note that the figure paths are relative
(`../Data/failure_study/plots/...`), so on Overleaf you must either upload
the four PNGs into the project and flatten the paths, or comment out the
`\includegraphics` lines while drafting.

## Finding the open items

Every unresolved item is deliberately greppable and renders in colour:

```
grep -n 'TODO\|PLACEHOLDER' main.tex
```

Red `[TODO: ...]` = something to do. Blue `[PLACEHOLDER: ...]` = a value to
fill in.

### Three things resolved while drafting, worth knowing about

1. **The 139-vs-144 trial question is settled.** `phase6_ablation.csv`
   contains exactly 144 data rows, and `phase6_ablation_summary.csv` is
   derived from it. The 139-trial numbers in `PHASE6_SUMMARY.md` §5 are a
   superseded interim analysis; the paper uses the full run and says so in
   a footnote. The internal 5-vs-6 discrepancy inside `PHASE6_SUMMARY.md`
   is therefore moot, though you may want to correct that file.

2. **The statistical methods were read out of the code, not assumed.**
   `phase6_ablation.py:mcnemar_test` uses `scipy.stats.binomtest(min(b,c),
   b+c, 0.5)` — an exact two-sided binomial McNemar, not a χ²
   approximation. The bootstrap is B=2000, percentile CI, `random.Random(0)`,
   resampling **paired per-trial differences**. All of this is now stated
   explicitly in §2.2, which closes a scored reviewer item.

3. **A real discrepancy with the source notes, corrected in the paper.**
   The discordant counts show per-trial *regressions*: 2 trials where
   Baseline succeeded but B failed, and 6 for D. `THEORETICAL_ANALYSIS.md`
   §9 reads Proposition 9 as "the reason no arm underperforms baseline" —
   that holds in aggregate but is false per trial. Proposition 9 bounds
   *resources*, not *outcomes*. The paper states this correctly in §1.10
   and §2.3. **You may want to fix the wording in the source notes too.**
